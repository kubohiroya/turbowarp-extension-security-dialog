# 0.8.5（2026-11-04）

`@kubohiroya/turbowarp-extension-security-dialog@0.8.5` は、0.8.4以降にマージされた
拡張選択画面の改善をまとめたnpm公開版です。

- 警告を、濃紺背景・白文字の閉じられるスナックバーへ変更。一覧やスクロール位置を動かしません。
- 各行をチェックボックス→アイコン→拡張名の順に配置。名前やアイコンからの選択を維持します。
- 認証アイコンは登録済みの紹介ページ、バージョン表記は該当版のGitHubリリースへリンクします。
- 概要の改行を保持し、HTTP(S)・mailto・メールアドレスをリンク表示します。
- 製作者の右横に登録済み連絡先を表示し、HTTP(S)・mailtoに対応します。
- 「キャンセル」「追加」を下部に常時表示し、内容部分だけをスクロールします。
  スナックバーはボタンを覆いません。
- 実行方法・保存方法のラベルに共通の装飾アイコンを表示します。読み上げ名は維持します。

実行許可・読み込み形式・既存のpropsは維持します。連絡先の`authorURL`はHTTP(S)に加えて
mailtoを受け付けますが、拡張コードのURLのHTTPS制約は維持します。
HTMLは文字列として表示し、リンクを開いても選択や許可は変わりません。

## 公開と出所

マージ後のcommitを`v0.8.5`タグにし、既存のRelease workflowで検証・pack・GitHub Releaseへの添付・
npm公開を行います。`latest`と`next`は0.8.5を指します。
配布物の`dist/build-info.json`にはversion、完全なrevision、`sourceState: "commit"`を記録します。
取り込み側はnpmアーカイブのintegrity、GitHub Release添付との一致、build-infoを確認できます。

## 検証と切戻し

既定の`pnpm run check`と、取得待ち/選択画面の実ブラウザ検証を実行します。
選択画面は日英・明暗・PC/Pixel7・低い画面を含み、固定ボタン・通知との非重複・リンク・
キーボード操作・選択状態を確認します。下流EditorのCIと公開確認は別に行います。

下流は直前の依存とlockfileへ戻せます。Editorの場合はversion `0.8.4`と
`67dbe996d92c8dbb3d954c2c4253cdd82eedb888`のGit固定が直前の組です。
公開済み0.8.5を削除・上書きせず、配布物の訂正が必要なら次の版で行います。
